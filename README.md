# EnergyWatch · ปทุมธานี

เว็บต้นแบบ (prototype) ที่กดใช้งานได้ของแพลตฟอร์มพลังงานระดับจังหวัด ออกแบบให้ตรงกับไฟล์ Figma "EnergyWatch - ปทุมธานี"
ใช้ข้อมูลตัวอย่างทั้งหมด ไม่มีฐานข้อมูลหรือ backend

ประกอบด้วย 3 ส่วนหลัก
- **แดชบอร์ดพลังงาน** (สีฟ้า `#4F8BC9`): รายจังหวัด, ข้อมูลย้อนหลัง, AI วิเคราะห์วิกฤต, รายงาน, ตั้งค่า
- **ตลาดไฟฟ้า P2P** (สีเขียว `#22A06B`): จับคู่ผู้ซื้อ-ผู้ขายไฟโซลาร์ในพื้นที่
- **ตลาดอุปกรณ์มือสอง** (สีส้ม `#F08C3A`): ซื้อขายแผงโซลาร์และแบตเตอรี่มือสองที่ตรวจรับรองแล้ว

## เปิดดูในเครื่อง

```bash
python tools/serve_prototype.py
```

แล้วเปิด <http://localhost:8780> (server นี้ปิดแคช แก้ไฟล์แล้วรีโหลดก็เห็นทันที)
หรือดับเบิลคลิก `prototype/index.html` เปิดตรง ๆ ก็ได้

## โครงสร้าง

```
prototype/                  เว็บต้นแบบที่กดได้ (ใช้ตัวนี้)
  index.html                หน้าแรก
  energy-*.html             หน้าแดชบอร์ด / ตลาด P2P / ตลาดมือสอง
  p2p-*.html, used-*.html   หน้า "กำลังพัฒนา" ของเมนูย่อยตลาด
  assets/
    base.css                เลย์เอาต์หลักและแถบซ้าย
    components.css          การ์ด ตาราง แท็บ ฟอร์ม สวิตช์
    responsive.css          ขนาดกะทัดรัด + รองรับแท็บเล็ต (<=1024px) และมือถือ (<=640px)
    sidebar.js              แถบซ้ายที่ทุกหน้าใช้ร่วมกัน + เมนูเลื่อนบนจอเล็ก
    app.js                  แจ้งเตือน "นี่คือต้นแบบ", แท็บ, สวิตช์, ดรอปดาวน์
    pages/*.js              การทำงานเฉพาะแต่ละหน้า

energy-*.html               หน้าออกแบบต้นฉบับ (ภาพนิ่ง 1440px สำหรับส่งเข้า Figma)
build_pages.py, build_home.py  สคริปต์สร้างหน้าออกแบบต้นฉบับ
tools/                      เครื่องมือแปลง HTML <-> Figma และ local server
```

## กฎการออกแบบ

- ไม่ใช้อิโมจิ ใช้ไอคอนเส้น (SVG) เท่านั้น
- ภาษาไทยทั้งหมด จังหวัดหลักคือปทุมธานี
- หน้าตลาดทั้งสองหน้าไม่มีฟีเจอร์ AI
- ปุ่มส่งข้อความ ยืนยัน หรือส่งออกไฟล์ จะขึ้นข้อความ "นี่คือต้นแบบ" แทนการทำงานจริง
